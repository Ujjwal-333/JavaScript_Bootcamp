Advanced Paddy Automation

JavaScript Controlled Agriculture Logic for Arduino

1 System Architecture

Hardware Stack

  • Arduino Board (Uno/Mega/Nano)
  • Capacitive Soil Moisture Sensor (A0)
  • Low-level Trigger Relay (Pin 8)
  • Water Pump (5V/12V)

Software Stack

  • Node.js Runtime
  • Johnny-Five Framework
  • Firmata Firmware

2 Improved Structured Code

Yeh code modular hai. Hardware configuration, Stage logic, aur Controller ko separate rakha gaya hai.

index.js (Modular Version) Ujjwal Pandey v2.0
// --- MODULE IMPORTS ---
const { Board, Sensor, Relay } = require("johnny-five");
const board = new Board();

// --- 1. GLOBAL SETTINGS ---
const SETTINGS = {
  PLANTING_DATE: new Date("2026-04-01"),
  PINS: { SOIL: "A0", PUMP: 8 }
};

// --- 2. LOGIC ENGINE: Growth Stage Tracker ---
function getPaddyStatus() {
  const today = new Date();
  const diff = Math.ceil((today - SETTINGS.PLANTING_DATE) / (1000 * 60 * 60 * 24));

  if (diff <= 15) {
    return { name: "Seedling", threshold: 700, action: true, tip: "Keep moist" };
  } else if (diff <= 60) {
    return { name: "Vegetative", threshold: 500, action: true, tip: "Flooding needed" };
  } else {
    return { name: "Ripening", threshold: 1024, action: false, tip: "Drain field" };
  }
}

// --- 3. CONTROLLER: Hardware Execution ---
board.on("ready", () => {
  const soil = new Sensor(SETTINGS.PINS.SOIL);
  const pump = new Relay(SETTINGS.PINS.PUMP);

  soil.on("change", () => {
    const state = getPaddyStatus();
    const moisture = soil.value;

    console.log(`Stage: ${state.name} | Moisture: ${moisture}`);

    // Action Logic
    if (state.action && moisture > state.threshold) {
      pump.on();
      console.warn("Pump ON: Watering Paddy...");
    } else {
      pump.off();
    }
  });
});

3 Wiring Summary

Pin Mapping:
- Soil Sensor: Connect to Pin A0 on Arduino.
- Relay Signal: Connect to Digital Pin 8.
- Pump: Cut the positive wire of your pump power source and connect it to the COM and NO (Normally Open) pins of the Relay.
